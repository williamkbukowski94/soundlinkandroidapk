# soundLInk Android APK

[Download soundLInk for Android](https://soundlink-download.vercel.app/) — public download page; no account needed.

Download the installable APK from [Releases](https://github.com/williamkbukowski94/soundlinkandroidapk/releases).

Install the same APK on each Android 10+ phone. Android may ask you to allow installation from your browser or file manager.

Choose Phone speakers or Bluetooth speakers on every phone (one mode per group). On the source, tap Share app audio over Wi-Fi, approve Android’s capture prompt, and play audio in another compatible app. Spotify may block capture and is not guaranteed. The source sends only; check the capture meter before lowering its volume. On the other phones, enter its Wi-Fi IPv4 address and eight-digit group code. All devices must use the same Wi-Fi without client isolation.

This is a debug-signed synchronization test build, not a verified guarantee of seamless acoustic playback. Start with two phones and calibrate using the shared clicks. Physical device testing remains required.
